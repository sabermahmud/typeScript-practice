# TypeScript Basic Problem Solving

A collection of TypeScript problem-solving exercises focused on building strong fundamentals and understanding TypeScript's type system through practical problems.

## 🎯 Topics Covered

* Function parameter and return types
* Conditional logic
* Boundary conditions
* Object types
* `type` and `interface`
* Typed arrays
* `reduce()`
* `filter()`
* Union types
* Literal types
* Type safety
* Discriminated unions
* Type narrowing

## 📝 Problems

### 1. Cinema Ticket Counter — `getTicketPrice`

Determines ticket price based on the customer's age.

### 2. Store Inventory Status — `getStockStatus`

Returns the appropriate stock status based on available quantity.

### 3. Social Media Profile Formatter — `formatUserProfile`

Converts a typed user object into a readable profile sentence.

### 4. Shopping Cart Calculator — `calculateCartTotal`

Calculates the total price of products in a shopping cart using `reduce()`.

### 5. Student Result Analyzer — `getStudentResult`

Calculates a student's average marks and determines whether they passed or failed.

### 6. Role-Based Permission Checker — `canEdit`

Uses union and literal types to restrict valid user roles.

### 7. Product Category Search — `findProducts`

Filters products based on their category using `filter()`.

### 8. Hospital Patient Status — `getPatientStatus`

Uses discriminated unions and type narrowing to handle general and emergency patients.

### 9. Bank Transaction Processor — `processTransaction`

Processes deposits and withdrawals using discriminated union types and conditional logic.

## 🧠 Learning Approach

For each problem:

1. Understand the input.
2. Define the required TypeScript types.
3. Define the function and return type.
4. Solve the core JavaScript logic.
5. Use TypeScript to make the solution type-safe.
6. Test normal cases and edge cases.

## 🚀 Goal

The goal of these exercises is not just to solve the problems, but to become comfortable with TypeScript's type system and improve problem-solving skills through hands-on practice.

**Learning by Solving. Building step by step.**
